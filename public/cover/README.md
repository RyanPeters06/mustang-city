# Cover art drop-in
- `cover.webp|png|jpg` — the full comic-panel collage (portrait 9:16 works best). Shown on the loading/title screen.
- or `panel-1.png`, `panel-2.png`, … — individual panels, cycled on the loading screen (sorted by name).
Original art only (see docs/COVER_ART.md). The wordmark is drawn in code — no text in the art.
